# Amazon Review Sentiment Analysis

This is a NLP and Machine Learning project where I built a sentiment analysis model to classify Amazon customer reviews as positive or negative.

The project helped me understand the complete workflow of a text classification problem, from data cleaning to model evaluation.

## Features

- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Text preprocessing
- TF-IDF Vectorization
- Logistic Regression model
- Word Cloud visualization
- Model evaluation

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- WordCloud
- Jupyter Notebook

## Project Workflow

1. Load the dataset
2. Clean and preprocess the reviews
3. Explore the data using visualizations
4. Convert text into numerical features using TF-IDF
5. Train a Logistic Regression model
6. Evaluate the model performance

## Results

- Model: Logistic Regression
- Accuracy: **88%**

## What I Learned

- Cleaning and preprocessing text data
- Performing EDA on textual datasets
- Using TF-IDF for feature extraction
- Training and evaluating a machine learning model
- Visualizing insights using Python
